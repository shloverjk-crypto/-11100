강화도어 업무 안내

강화도어 설치나 교체를 알아본다면, 출입문이 필요한 위치와 현재 상태, 원하는 작업을 먼저 정리해보세요.

DOOR PROJECT

어떤 정보를 정리하면
좋을까요?

강화도어는 젊음금속이 안내하는 업무 분야입니다. 기존 문을 교체하는지, 새로 설치하려는지와 출입 공간의 조건을 구분하면 요청 범위를 설명하는 데 도움이 됩니다.

실제 유리 사양, 부속 구성, 안전 기준, 작업 범위는 현장에 따라 확인해야 하며 이 페이지에서는 특정 성능을 약속하지 않습니다.

BEFORE ASKING

문의 전에 적어둘 네 가지

기본 정보를 정리해두면 설치·교체 요청을 분명히 전달할 수 있습니다.

01

현장 위치

공사 예정 지역과 출입 공간의 용도를 적습니다.

02

작업 구분

신규 설치, 교체, 수리 중 어떤 내용을 검토하는지 정리합니다.

03

문 상태와 크기

현재 상태나 대략적인 치수를 알고 있다면 참고 정보로 준비합니다.

04

현장 사진

보유한 사진이나 도면으로 출입 공간을 설명합니다.

CHECK ON SITE

현장에서 확인할 조건

문 크기, 개폐 방향, 주변 바닥과 벽의 상태, 기존 부속의 처리 여부 등은 현장별로 확인할 항목입니다. 현재 제공된 자료에는 상세 작업 범위가 없습니다.

수리와 교체 중 무엇이 적절한지는 문 상태를 확인하지 않고 단정하기 어렵습니다.
